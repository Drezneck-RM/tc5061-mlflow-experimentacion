# Resultados verificables

Esta carpeta conserva los resultados de la serie `entrega-final`: comparación de seis configuraciones, sensibilidad local de hiperparámetros, prueba de reproducibilidad y predicciones de la configuración seleccionada.

Los archivos `selected_*` documentan parámetros, entorno, protocolo, huellas del código y datos, recarga del modelo y evaluación descriptiva. El bloque final ya había sido examinado en la actividad anterior; no es un conjunto de prueba independiente.

La base de datos de MLflow y los modelos se regeneran siguiendo los comandos del README principal. La guía `GUIA_EXPLICADA.md` explica cómo interpretar cada evidencia.
